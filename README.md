# Smoluchowski-Equation-and-the-Evolution-of-Primordial-Black-Hole-Clusters
This repository provides Python codes that utilize Monte Carlo methods to solve the Smoluchowski coagulation equation, which can be effectively applied to model the merger processes within primordial black hole (PBH) clusters. If you find this code useful for your research, please cite the following papers: \(\texttt{arXiv:2507.07171}\) and \(\texttt{arXiv:2604.01684}.\)
